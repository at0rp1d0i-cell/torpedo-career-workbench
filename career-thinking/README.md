# 职业方向思考

这里只保留可填写结构，不包含作者偏好或真实职业决策。

## 当前结论

示例主方向：基础设施工程；这是待验证假设。

## 使用方式与管理边界

[options.md](options.md) 记录方向与门槛；[preference-signals.md](preference-signals.md) 记录真实偏好信号；[role-reality-notes.md](role-reality-notes.md) 记录工作日常；[decision-log.md](decision-log.md) 保留判断修订；[project-probes.md](project-probes.md) 记录最小验证项目；[retros/](retros/README.md) 保存每个招聘周期的复盘。

多个机会重复信号才回流长期判断。单次失败不自动改写方向；个人判断应留在私有仓库。
